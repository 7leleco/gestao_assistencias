# 🛠️ Gestão de Assistências
Sistema interno para gerenciar assistências técnicas da empresa **Alha Resoluções Residenciais**

## 📋 Sobre o projeto
Sistema web para cadastro, listagem e gerenciamento de ordens de serviço, com geração de checklist e pdf.

## 🚀 Tecnologias
-**Backend** Python + FastAPI + SQLite + SQLalchemy

## 📦 Como rodar
1.Clone o repositório
2.Crie um ambiente virtual:'python -m venv venv'
3.Ative o ambiente:'venv\Scripts\activate'
4.Instale as dependências:'pip install -r requirements.txt
5.Rode o servdor:'python app/main.py'
